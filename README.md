## 四项任务的核心结论速览

### 01 战力报告核实
- 原报告称「官方从未公布 7 分门槛」——**错误**。S40 公告 [10][11] 明确写「若结算评分小于 7 分，转化分数为 0」。
- 另有 5 处引用与原文不符、3 条链接失效。
- HTML 原版阅读困难：信息密度过高、横向溢出、缺少导航 → 重做为线性单页。

### 02 月报审核
- v1 查出 18 个问题（不含文档中已有的 19 条评论）。
- v2 复核：6 已修 / 10 未修 / 4 新增 / 10 条风险项。
- 周报比对：月报对「周末活动」「版本节奏」的解读与周报原始记录存在时滞差。

### 03 交易行研究
- 核心区分：**MLBB 手续费 5% 向买方收；HOK 2% 向卖方收**。
- 但**手续费方向不能直接翻译成「保护谁」**——名义收取方 ≠ 实际负担方。HOK 因为只能买最低价，卖方无法转嫁 2%，是卖方承担。真正保护买方的是「只能买最低价」规则，与手续费无关。
- HOK 真正的反套现闸门是**每周 2,000 提取上限**，不是手续费。
- 六部件分析框架：可交易池 / 产出渠道 / 定价机制 / 撮合结算 / 货币层级 / 闸门。

### 04 新手访谈审核
- 4 个 A 级问题（必须改）、4 个 B 级（两轮口径不一致）、6 个 C 级（表述瑕疵）。
- **一次自我修正**：最初把「高活玩家温暖局穿皮肤」判为理解错误，经逐字稿核验**原话真实存在**。判错原因是用通用定义否定内部术语。
- 文档确实存在三处压缩失真：删触发条件、去掉 AI 主体、加入作者提炼的中间机制。
