# MLBB vs HOK 寄卖行/拍卖行：机制能力范围与风险对比

- 日期：2026-10-30
- MLBB 信源：内部设计流水《拍卖行相关 26.10.26（年度复盘）》（docx `QD2rdswiVounkOxh9DrcprpQnjz`，rev 10867）——**一手**
- HOK 信源：印尼 S15 端内实测确认版（**A 级**，机制主体）、团队周报（一手采集）、2026-10-26 交易系统会议纪要（二手）、Fandom Wiki
- **修订记录**：2026-10-30 修正手续费数字。原写"HOK 10%"系将三角洲/Free Fire 的数据误归给 HOK；现更正为 **2%，向卖方收**（来源：印尼 S15 实测）
- 用途：机制对照，供产品/运营判断"哪些能做、哪些不能做、风险在哪"

---

## 一句话结论

**两家的目标是一致的（都为活跃），但实现路径是两套完全不同的风控模型：**

- **MLBB = 一级货币 + 强闸门 + 强调控**：用解绑、冷却、大区隔离、机器人、价格上限把风险锁死，代价是灵活度低、成交效率低
- **HOK = 二级货币 + 弱闸门 + 广供给**：用货币隔离兜底，把交易行做大，代价是货币一旦失控会反噬商业化

**关键差异只有一条**：HOK 已经敢在**商业化抽奖**里直接产可交易物，MLBB 目前 99.9999% 靠**棒棒卡（活跃）**，只用一个"解绑道具"开了道小口子。**我们要不要跨这步，决定了后面所有风险敞口的形状。**

## 三、风险对比

按"我方会议里提出的三层担忧"来分。

### 第一层：短期 —— 抽奖流水被自己稀释

| | MLBB 现状 | HOK 现状 |
|---|---|---|
| 是否有此风险 | **低**（当前没在抽奖里产可交易物） | **未知，但结构性存在** |
| 风险机制 | — | 抽奖同时产"自用版"和"可交易版" → 可交易版流入市场 → 玩家可能选择"买二手"而非"自己抽" |

**我方会议原话（10-26）**：
> 「他们商业化活动中产出这种可交易道具，会不会冲击他们本身的商业化抽奖？」

**我的判断**：这个风险的真实程度，取决于**交易行价格 vs 抽奖期望**的关系。若二手价长期低于抽奖期望，抽奖会被分流；若高于，抽奖反而被"套利需求"推高（囤货）。犬夜叉从 4,037 涨到 12,000+ 说明**发行期后就脱离了抽奖锚**，但发行期内的分流效应目前无数据。

> **可验证的最小动作**：找一款 HOK 商业化抽奖的上架资源，记录"发行期内交易行最低价 vs 抽奖期望成本"的比值。低于 1 就是分流，高于 1 就是刺激。

---

### 第二层：中期 —— 货币体系被拖垮

这是**我方结构上比 HOK 更危险的一环**。

| | MLBB | HOK |
|---|---|---|
| 交易货币层级 | **一级（钻石）** | **二级（奇珍点券）** |
| 崩了会怎样 | 直接影响全部商业化定价体系 | 只在交易行内循环，可隔离 |
| 我方会议原话 | 「**因为我们是一级货币，它是二级货币嘛…这还包括我们可能会产生黑产，比它大一点**」 | — |

**为什么我方更危险**：

```
MLBB：卖东西 → 拿到钻石 → 能买任何东西（含抽奖/战令/直售）
      → 交易行事实上成了一个"付费替代通道"
      → 一旦规模化，等于官方给自己开了个打折入口

HOK： 卖东西 → 拿到奇珍点券 → 只能买限定系统里的东西
      → 交易行是一个"闭环游乐场"，漏不到主付费体系
```

**这是 HOK 最聪明的一步**：不是它风控做得好，而是它**从货币层就把风险切断了**。我方没有这道保险，只能靠解绑、冷却、大区、机器人这些"事后闸门"。

---

### 第三层：长期 —— 返场砸盘与口碑

| | MLBB | HOK |
|---|---|---|
| 是否已形成溢价 | 有迹象：龙晶（黄/蓝）、哭泣表情被内部数据标为"溢价且成交率高" | **已形成**：犬夜叉 4,037 → 12,000+（约 197%） |
| 返场会怎样 | 同样的砸盘风险 | 同样的砸盘风险 |
| 我方会议判断 | 「**我们要么就不返场，不能做这件事**」 | 未公开表态 |

**这一条是两家共同的死结**，没有技术解，只有策略解：

- 一旦交易行形成溢价 → 老玩家用高价接盘 → 官方再返场 = 自己砸盘 + 口碑反噬
- 不返场 → 资源永久绝版 → 交易行变成"存量博弈"，新人无货可买 → 市场萎缩

**HOK 已经踩进这个循环了**（犬夜叉溢价 3 倍、挂单只有 5 个 = 极度缺货）。它的应对还没看到公开答案——**这正是最值得盯的观察点**。

### 补充风险：我方有、HOK 没有的

| 风险 | 说明 |
|---|---|
| **解绑道具带来的摩擦** | 200 钻解绑费 + 多一步操作，会压低"商业化资源"的流通率。好处是防黑产，坏处是想卖的人也被挡住了 |
| **5% 向买家收的手续费** | 抬高买方成本 → 影响成交率。会议已意识到：「手续费定得越高…影响成交率」 |
| **机器人依赖** | 上架机器人 + 回收机器人是"人造流动性"。一旦撤掉，真实供需会暴露得很赤裸 |
| **交易大区隔离** | 降低跨区效率，也降低了黑产空间。但会造成"某些区有价无市" |

### 补充风险：HOK 有、我方暂没有的

| 风险 | 说明 |
|---|---|
| **奇珍点券崩盘** | 二级货币供给失控 → 交易行物价飞涨 → 整个交易生态失信 |
| **抽奖分流** | 见第一层 |
| **官方下场嫌疑** | 纪要提到 FF "很多上架可能是官方放的"，玩家端全是黑盒。HOK 若被怀疑官方下场，信任会崩 |

## 四、三个关键判断

### 判断一：我方已经建成了"可控市场"，HOK 建成的是"自由市场"

| 我方 | HOK |
|---|---|
| 有央行（底价、20% 上限、机器人、动态补货） | 匿名撮合，未见干预 |
| 投放颗粒度到"这个玩家有没有这个英雄" | 投放颗粒度粗 |
| 结果：**风险低、效率也低** | 结果：**效率高、风险也高** |

**这不是谁做得更好的问题，是两套不同的赌注**。我方押"控得住"，HOK 押"跑得起来"。

---

### 判断二：HOK 的二级货币是它的核心护城河，也是我方最该学的一课

纪要里 HOK 被评价为"**保守一步、胆大一步**"：

- **保守**：反复评估后**没有开一级货币**，交易行锁死在奇珍点券
- **胆大**：把**商业化抽奖**接进了可交易池

这个组合很精：用货币隔离吸收风险，用商业化供给做大流量。

**如果我方要跟进商业化产可交易物，第一个该问的不是"产多少"，而是"能不能也上一个二级货币壳"**——否则就是拿掉保险去跑。

---

### 判断三：铭牌的"解绑道具"是我方目前最聪明的设计，值得放大

38 版本的铭牌设计：

```
抽奖获得铭牌 → 想卖的人花 200 钻解绑 → 才能上架
```

这一步有三重作用：

1. **筛人**：不想卖的人根本不会解绑，天然过滤掉"顺手挂上去"的噪音
2. **防黑产**：解绑要花钱，抬高了刷号套利成本
3. **留后门**：既满足"抽奖资源可交易"，又不破坏抽奖的主循环

**这是我方在"要不要让商业化资源进拍卖行"这个问题上，给出的第一个可行答案**——比 HOK 的"直接可交易"更保守，但风险可控得多。

## 五之二、HOK 交易规则补充（印尼 S15 实测确认）

以下细则是原版对比之外补入的关键信息，**其中「买方只能买最低价」这条比手续费重要得多**。

| 规则项 | 内容 |
|---|---|
| 挂售槽位 | **1 → 8，随赛季段位逐步解锁** |
| 公示期 | 上架后 1 天（个别 1 小时），公示结束方可购买 |
| 挂单有效期 | 3 天，到期未售自动下架 |
| 购买限制 | **只能买当前最低价，不可选择更高档位**；低价售罄后次低价轮替 |
| 成交交付 | 邮件发放；未使用可再次上架 |
| 可交易品类 | 6 类：皮肤 / 道具 / 灵宝 / 个人主页装扮 / 活动道具 / 播报 |
| 奇珍点券边界 | 可买寄卖行商品 + 本赛季更新前已直售的旧皮肤；不可赠礼、不可抽奖、不可反向兑回、不可提现 |
| 提取上限 | 每周 2,000 奇珍点券，超出顺延 |

**为什么「只能买最低价」是核心设计**：它取消了买方的选择权，也取消了卖方的溢价空间——**同质商品之间只能打价格战**。结果就是：HOK 寄卖行在**同质品类（活跃资源）上天然趋近平价**，只有在**非同质品类（稀缺、绝版、联动）上才会出现溢价**。

**这正好解释了此前观察到的「双轨市场」现象**，也解释了为什么犬夜叉能溢价 3 倍（唯一、不可替代），而活跃宝箱只能走量。

## 五之三、关于手续费方向的一个语义纠正

容易犯的错，是把"向谁收钱"直接翻译成"保护谁"。**这个映射不成立。**

### 为什么不能这么推

**第一，名义收取方 ≠ 实际负担方。**

HOK 的规则是买方只能买最低价，卖方处在比谁更便宜的赛道里——**一旦为了转嫁 2% 而涨价，就直接掉出最低价档，根本卖不出去**。所以这 2% 卖方转嫁不了，是实打实自己吃掉的。

既然卖方全吃，那它就是对**供给端收的小额税**，谈不上"保护买方"。

**第二，真正保护 HOK 买方的是另一条规则。**

买方不会被坑，靠的是"只能买最低价"——价格被压在地板，想买贵也买不到。**这跟手续费收谁没有关系。**

### 正确的对照方式

不看"保护谁"，看"用手续费解决什么问题"：

| | MLBB 5% 向买方 | HOK 2% 向卖方 |
|---|---|---|
| **要解决什么** | 黑卡退款 | 平台分佣 + 运营杠杆 |
| **为什么收这一边** | 黑卡是"买家充值后退款"，收在买方最直接拦得住 | 从卖家收益里扣最自然（结算页即：总售价 − 手续费 = 预计收益） |
| **本质** | 风控闸门 | 抽成 |
| **是否收入设计** | 否（会议原话："我们不是靠它赚钱"） | 部分是，但 2% 太小，不是主力 |

**我方坚持不收卖方，真实取向是「不向提供 DAU 的那一端加摩擦」，而不是笼统的"保护卖方"。**

### 那 HOK 为什么向自己服务的卖方收钱？

2% 太小，主因不太可能是赚钱，也不太可能是风控——**真正的套现闸门是「每周 2,000 的提取上限」**。更合理的解释是三点叠加：

1. 给系统一个**存在感**，让玩家知道"交易是有成本的"
2. 给一个**心理锚**，抑制纯套利心态（最怕被当成提款机）
3. 常态收 + 活动免，把"免手续费"留作一个**可用的运营手段**

---

## 六、如果只记一句话

> **HOK 用「二级货币」把交易行的风险关在一个房间里；我方用「一级货币 + 一堆闸门」把交易行的效率关在一个房间里。**
> **两边都在为「活跃」服务，但 HOK 多了一层可以承受失败的缓冲，我方没有。**
> **所以：我方要跟进「商业化资源可交易」，先想清楚要不要补上那层缓冲（二级货币壳或等价隔离），再谈投多少。**
