## 四、重点二 · 寄卖行：玩家可交易道具市场

（重要程度高 · 印尼已实测上线，本节内容为实测确认版）

> 实测说明：寄卖行已在印尼地区随 S15 实测上线，本节内容全部基于游戏内实测规则与界面整理，属实测确认口径。该系统目前以试运营形式分批灰度开放，后续是否常驻及其他区域的开放节奏以官方公告为准。

**它是什么**：随 S15 上线的玩家间可交易道具市场。交易采用中央匿名撮合——玩家不与特定对手直接交易，而是由系统按价格统一撮合；全流程以专用代币「奇珍点券」结算。

### 可交易品类（6 类）

| 品类 | 获取途径 |
|---|---|
| 皮肤 | 龙吟宝阁、伟大宝路、赛季活动 |
| 道具 | 龙吟宝阁、伟大宝路、赛季活动 |
| 灵宝 | 龙吟宝阁、伟大宝路、赛季活动 |
| 个人主页装扮 | 龙吟宝阁、伟大宝路、赛季活动 |
| 活动道具 | 龙吟宝阁、伟大宝路、赛季活动 |
| 播报 | 龙吟宝阁、伟大宝路、赛季活动 |

> 获得「可交易物品」后既可自用也可直接上架寄卖行。

### 卖方：上架与定价

| 规则项 | 说明 |
|---|---|
| 定价方式 | 系统给出推荐价浮动区间，玩家在区间内自行定价；也可参考「历史成交价档」与成交量来自设更高价格 |
| 价格上限 | 品类不同上限不同，设有上限 |
| 挂售槽位 | 与赛季段位挂钩，初始 **1 个**，随段位提升逐步解锁至最多 **8 个** |
| 公示期 | 上架后进入公示期（一般 **1 天**，个别 **1 小时**），公示结束方可购买 |
| 挂单有效期 | **3 天**，到期未售自动下架 |
| 成交后交付 | 通过**邮件发放**；购入后如未使用，可**再次上架**出售 |

### 买方：购买规则

| 规则项 | 说明 |
|---|---|
| 价格展示 | 同一商品按价格**由低到高**展示 |
| 购买限制 | 只能购买当前在售的**最低价格**，不可主动选择更高价格档位 |
| 价格轮替 | 低价档全部售罄后，次低价档才会轮替为可购买档位 |
| 无货状态 | 某物品无人出售则显示「**无**」 |
| 撮合规则 | 交易全程中央匿名撮合，一经成交即**不可撤销、不可退款** |

### 手续费与结算

| 项目 | 规则 |
|---|---|
| 手续费率 | 成交价的 **2%**（从卖方所得中直接扣除） |
| 单笔最低 | **1 奇珍点券** |
| 减免 | 官方可依活动减免或调整费率 |
| 结算货币 | 扣除手续费后余额以「**奇珍点券**」结算 |

### 奇珍点券：使用范围

| ✅ 可以用于 | ❌ 不可用于 |
|---|---|
| 购买寄卖行其他玩家挂出的可交易外观 | 赠礼 |
| 购买商城**本次赛季更新前已直售过的旧皮肤** | 抽奖 |
| — | 反向兑回点券 |
| — | 退款 / 提现 |

> 用点券兑换奇珍点券时，所消耗的点券可正常获取贵族积分；但后续用奇珍点券消费本身**不增加**贵族积分。

| 规则项 | 说明 |
|---|---|
| 每周提取上限 | **2,000** 奇珍点券，超出部分顺延至次周 |
| 支付扣费顺序 | 抵扣券 → 限时点券 → **奇珍点券** → 点券 |

> **实测总结**：寄卖行随 S15 在印尼地区上线后已完成全面实测，核心机制全部观测到位——
> - **撮合**：中央匿名撮合，一经成交不可撤销
> - **结算**：奇珍点券结算，成交收取 2% 手续费（单笔最低 1、可依活动减免）
> - **买方**：只能购买当前最低价，不可选档；低价售罄后次低价轮替
> - **卖方**：推荐价区间内定价，挂售槽位 1→8（随段位解锁）
> - **流程**：上架公示 1 天（个别 1 小时）→ 挂单 3 天 → 到期未售自动下架 → 成交后邮件发放
> - **品类**：皮肤 / 道具 / 灵宝 / 个人主页装扮 / 活动道具 / 播报（6 类）
> - **货币**：奇珍点券不可提现、不可反向兑回、不增加贵族积分（但点券兑换时可正常获取）
> - **扣费顺序**：抵扣券 → 限时点券 → 奇珍点券 → 点券
> - **提取上限**：每周 2,000 奇珍点券
>
> **仍待观察**：对一手皮肤销售的实际冲击、是否长期常驻、其余区域开放节奏、奇珍点券在二级市场的活跃度与价格走向。
