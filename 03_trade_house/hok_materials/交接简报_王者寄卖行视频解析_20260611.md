## 三、玩法机制摘要

「寄卖行」核心闭环：**完成活动获取「可交易道具」→ 上架寄卖行出售 → 赚「奇珍点券」→ 用点券购买心仪物品**

| 要素 | 说明 |
|---|---|
| 奇珍点券（Curio Token） | 寄卖专属货币；可交易，也能购买 6.17 前商城直售皮肤 |
| 可交易道具 | 活动获取的可交易宝箱 / 皮肤 / 名片（标 tradable） |
| 寄卖市场 | 上架定价，显示最低价/在售数/近期成交价/推荐价/预计收益 |
| 龙吟宝阁（兑换商店） | 用 Dragon Emblem 等货币兑换可交易物 |
| 交易手续费 | 常态收取，活动期免除 |
| 段位门槛 | 部分上架位随段位解锁（Gold I / Diamond I） |
| 交易记录 | 购买/出售记录保留约一年，最多 30 条 |

## 四、简单分析要点

1. **本质**：玩家驱动的二级交易市场（P2P Marketplace），把厂商单向直售扩展为玩家间流通。
2. **设计意图**：提升活动道具价值 → 用奇珍点券构建内循环经济 → 收益重新引导回系统消费；段位绑定上架位 + 手续费用于防黑产/防通胀。
3. **风险点**：定价通胀、工作室搬砖、对商城直售收入的分流。
4. **对我方参考**：①可交易范围圈定（只放活动产出）控制收入影响；②免手续费冷启动培育市场；③段位绑定经济系统的设计巧思。
